# More compact GM window layout

The GM window takes too much space.

**Decided (Justin, 2026-11-09):**

- **Labels beside values,** statblock style ("Points 4", "Round 3 / 5" on one line), instead of boxed fieldsets with legends.
- **Skill grid:** Discovery and Influence skill chips in a 2–3 column grid instead of wrapping lines.
- **One header strip:** round controls, Start/End/Reset, Hide/Show panel and the party chips merge into one strip at the top.
- Not chosen: folding sections.

**Next step:** mock the Run view in the sheet template and CSS, then check it with a live challenge of two NPCs. The PF2e look ([[gm-window-monster-style]]) follows.
