# Show Edit mode skill checks as a labeled grid

In Edit mode, the Discovery and Influence skill checks should use a table, one row per skill.

Put the field names in the table header, so each skill row does not repeat them.

**Columns:** Skill, Lore name, DC, Revealed, Decoy, delete. The Lore name cell is empty unless the skill is Lore. Universal rows leave Revealed and Decoy empty, as today.

**Done when:** Edit mode shows both tables on a live challenge, and editing a cell still saves.
