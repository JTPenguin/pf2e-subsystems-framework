# Decide: remove the Ongoing / One-Time / Repeating types from weak, resist and other

Weak, resist and other entries fall into three kinds today:

- **Ongoing:** a permanent change.
- **One-Time:** applies to one roll, or happens once.
- **Repeating:** applies each time a condition is met.

Repeating is not a real mechanic in the PF2e Influence subsystem.

**Options:**

1. **Remove the type concept.** The GM decides when each entry applies. This is mostly how it works today.
2. **Add Repeating as a real type.** The module would need to check the condition and apply the entry on its own.

**Recommendation:** option 1. It is simpler, and it matches the subsystem's rules.

**Done when:** Justin picks an option. If option 1, the type field and its UI come out of the module.
