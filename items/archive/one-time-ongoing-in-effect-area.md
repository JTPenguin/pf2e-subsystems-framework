# Move One-Time / Ongoing next to the effect

One-Time vs Ongoing only matters for DC Changes. Right now it sits in a shared spot, so users must think about it even when they pick another effect.

**Plan:**

- Move the One-Time / Ongoing dropdown into the effect area of the modifier. It then shows only when the effect is DC Changes.
- Move the chip next to the effect in the challenge sheet window.
- Use the same pattern on the cards in the panel.
