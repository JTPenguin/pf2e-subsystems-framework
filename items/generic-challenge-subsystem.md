# Decide the design for a generic, flexible subsystem for other challenges

Justin wants a generic subsystem a GM can use for other kinds of challenges. It would sit beside Influence, Chase, Research and Infiltration.

The design needs Justin's sign-off first. Open questions:

- What does a GM set up: actions, skills, DCs, and point thresholds?
- How much of the rules is fixed, and how much does the GM choose?

This item waits on [[generic-subsystem-shared-mechanics]], since the flexible subsystem needs the shared parts.

**Done when:** Justin approves a design. Then build it as a new item.
