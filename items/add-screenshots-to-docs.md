# Add screenshots to the README and GM guide

The README and the GM guide are text only. A GM reading them cannot see what the challenge sheet, the run view or the player panel looks like. Justin asked for screenshots in one or both documents.

## Scope

- **Where:** `README.md` and/or `docs/gm-guide.md`. Justin said "and/or", so the choice of document is open. Start with the GM guide, since it explains how to run a challenge.
- **What to show:** the main views a GM uses: the challenge sheet, the run view, and the player panel over the canvas. Pick the fewest shots that cover the guide's sections.
- **Where the images go:** a `docs/images/` folder, with the images linked from the Markdown.

## Next step

Take the screenshots in a live Foundry session with the Example Challenges compendium loaded, then add them to the chosen document with a short caption each. Check the result by viewing the rendered Markdown.

## Done when

The chosen document shows each screenshot next to the text it supports, the images are in `docs/images/`, and the links work on GitHub.
