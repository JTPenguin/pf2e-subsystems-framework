# Tidy modifier headers and show the effect in the header

Modifier headers do not line up neatly. Justin wants them arranged more cleanly. He also wants the modifier's effect shown in the header, so a GM can read what a modifier does without opening it.

## Scope

- **Layout:** arrange the parts of a modifier header in a tidier, consistent order and alignment. Check the header on both the challenge sheet and the player panel.
- **Effect:** show the modifier's effect in its header. Check how the effect is already shown in the modifier card and reuse that wording.
- **Docs:** if the header change alters what a GM sees, update `docs/gm-guide.md` in the same change.

## Next step

Read the current modifier header markup and styles. Propose the new header layout to Justin before building it, unless he has already approved the layout.
