# Implement the Infiltration subsystem

Build the Infiltration subsystem in the module, like the Influence subsystem. Its actions include Forge a Document.

Build its actions and skills on the shared parts from [[generic-subsystem-shared-mechanics]], not on bespoke code.

**Done when:** a GM can run an infiltration challenge from a sheet, and players can take its actions from the panel, including Forge a Document. Check it in Foundry with a live test challenge. Confirm the subsystem's rules against `docs/spec.md` first.
