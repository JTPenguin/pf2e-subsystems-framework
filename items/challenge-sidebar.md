# Add a sidebar to the challenge sheet for challenge-level fields and info

The challenge sheet keeps its challenge-level fields and info in the main body. Justin wants a sidebar that holds them, so the main body can stay on the subjects, counters, actions and modifiers.

## Open questions for triage

- Which fields and info move into the sidebar, as opposed to staying in the main body.
- Which side the sidebar sits on, and whether it stays visible while the main body scrolls.

## Next step

Triage with Justin, then a plan for the layout. No implementation until Justin says go.
